# Code of Conduct

ReMTP follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and don't harass anyone.
Maintainers may edit or remove comments, issues and contributions that don't follow it, and may ban
repeat offenders.

To report something privately, use GitHub's **Report content** on the comment, issue or pull request (its
**⋯** menu), or GitHub's [abuse report form](https://github.com/contact/report-abuse) for anything else.
These reports go to GitHub, which can act on them; this project has no separate private channel.
